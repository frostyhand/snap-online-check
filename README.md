# SNAP Online Check

Do AI assistants send SNAP households to stores that will take their EBT card online?

I asked Google Gemini with live search 624 questions a SNAP shopper might ask, from the largest city in every state and DC, and scored every answer against each retailer's own policy and store locator.

**Wave 1 (22 and 23 November 2026):**

- 97.9% of 423 named-retailer questions answered correctly, with no wrong "no" answers.
- All 7 wrong "yes" answers pointed to a chain with no store serving the shopper's city.
- 12 of 104 open answers (11.5%) named at least one store that cannot serve the shopper.
- 0 answers said SNAP can pay delivery fees; only 3 of 104 told the shopper to confirm with USDA, the state agency or the store.
- USDA's own state lists leave out 17 retailer and state pairs where the retailer does take EBT online.
- Neither agent checkout protocol (UCP, ACP) can carry an EBT payment.

Full write-up: [FINDINGS.md](FINDINGS.md). Method: [PROTOCOL.md](PROTOCOL.md), written before the run, with the two hand-check layers added after wave 1 and marked as such.

## What is here

| Path | What it holds |
| --- | --- |
| `data/raw/runs.jsonl` | Every prompt and full answer, with the model version served and its search sources |
| `data/derived/codes.jsonl` | Each answer coded into stores named, verdict, fees and pointers to official sources |
| `data/derived/checks.csv`, `stores.csv` | One row per named-retailer question and per store named, with the score |
| `data/reference/retailer_policies.json` | Layer 1 of the answer key: each retailer's SNAP online policy and footprint, with sources |
| `data/reference/adjudications.csv` | Layer 2: hand check of every disagreement, with sources |
| `data/reference/city/` | Layer 3: whether each chain serves each city, from store locators, with sources |
| `data/reference/usda_snap_online.csv`, `snapshots/` | USDA state lists from Internet Archive captures, December 2025 to June 2026 |
| `data/reference/usda_snap_online_live.csv`, `usda_live/` | The same pages read live from a US connection on 23 November 2026 |
| `results/summary.md` | Headline numbers, regenerated by `study.score` |

## Run it

Needs Python 3.12 and a Gemini API key with search grounding (billed on paid tiers). Put `GEMINI_API_KEY=...` in `.env`.

```bash
uv venv && uv pip install httpx pytest
.venv/bin/python -m pytest -q
.venv/bin/python -m study.run --model gemini-flash-latest --place tx --limit 12     # pilot
.venv/bin/python -m study.run --model gemini-flash-latest                          # full wave, resumable
.venv/bin/python -m study.extract --model gemini-flash-latest
.venv/bin/python -m study.score
```

Every step resumes where it stopped. A local ledger caps calls per UTC day (`DAILY_CAP` in `study/gemini.py`).
